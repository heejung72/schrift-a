# 5장 보고서 수치 — 창의성·차별성

평가 요건: 방법 나열이 아니라 **2·3장 결과와 연결**해 효과를 수치로 증명한다.
본 프로젝트의 차별점은 "전통 제조업 통계기법(SPC)과 ML의 결합"을 중심으로 5가지가 서로 맞물린다.

## 5.1 제조지식 + SPC 결합 피처 (핵심 차별점)

**아이디어**: 현재 공정 수치보다 **공정의 변화 흐름과 통계적 이상**이 불량의 선행 신호라고 보고, 전통 SPC 관리도 개념을 피처로 설계.

| 피처 | 제조/통계 근거 |
|---|---|
| `{var}_ewma_resid` (6개) | EWMA 관리도 잔차 = 최근 추세 이탈도 |
| `ewma_resid_norm` | 6개 변수 이탈의 L2 복합 크기 |
| `spc_violation_count` | rolling 3-sigma 관리 한계 위반 변수 수 |

**2·3장과의 연결 (효과 증명):**
- SHAP 중요도 **Top4 중 3개가 신규 Rolling·SPC 피처**(`ewma_resid_norm` 1위, `Cycle_Time_ewma_resid` 3위, `spc_violation_count` 4위) — 3.1절.
- 검사 우선순위 **상위 20% 포착률 52% → 62% (+10%p)** — 2.4절.
- 금형별 독립 계산으로 cn7/rg3 스케일 차이 문제를 회피(1.5절 정규화 특이사항 대응).

## 5.2 불균형 학습 (1:56 불균형 대응)

| 기법 | 적용 |
|---|---|
| `class_weight="balanced"` | LR·RF |
| `scale_pos_weight=55` | LightGBM (≈ 양품/불량 비율) |
| fold별 F1 최대화 임계값 탐색 | 모든 모델 동일 적용 |

**연결**: 성능 향상 단계(2.2절)에서 기본 F1 0.222 → 임계값 최적화 0.266으로 상승. 불균형 1:56에서 정확도 대신 F1·PR-AUC를 주 지표로 선택(1.4절).

## 5.3 앙상블 (소프트 보팅)

- RandomForest(배깅) + LightGBM(부스팅) **소프트 보팅**. 서로 다른 오류 구조가 상호 보완.
- **LR을 의도적으로 제외**: LR 포함 시 앙상블 PR-AUC 0.258 → 0.202로 하락(약한 모델이 품질 저하). "앙상블은 무조건 넣는다"가 아니라 **근거 기반 선택**임을 보임.

**연결**: 4개 모델 동일 조건 비교에서 앙상블 F1 **0.343**(최고), Brier **0.015**(최저) — 2.2절.

## 5.4 확률 보정 품질 (Brier score)

- 3단계 판정은 "확률의 순위"가 정확해야 신뢰할 수 있다. 앙상블 Brier **0.015**로 4개 모델 중 최저 → 확률값 자체가 잘 보정됨.
- RF의 `class_weight`와 LGB의 `scale_pos_weight`가 확률을 과도하게 1로 밀지 않도록 조정.

**연결**: 잘 보정된 확률 → 검사 우선순위 곡선(2.4절)과 percentile 3단계 판정(3.5절)의 신뢰 근거.

## 5.5 불확실성 기반 3단계 판정 (미탐지 위험 분산)

**아이디어**: 양품/불량 2분법 대신, 확률 분위로 **"확실히 통과 / 불확실 / 즉시검사"** 3단계로 나눠 미탐지(FN)를 재검사 구간으로 흡수.

| 구간 | 검사 범위 | 건수 | 불량 포착 |
|---|---|---|---|
| 즉시검사 | 상위 5% | 121 | 13개 |
| 재검사 | 상위 6~20% | 359 | 13개 |
| 통과 | 하위 80% | 1,913 | (잔존 16개) |

**연결 (3장 FN 분석으로 정당화):**
- 3장에서 FN 불량은 `ewma_resid_norm`·`spc_violation_count`가 정상 범위 → "측정 변수만으로 양품과 구분 불가"(라벨 충돌 구간, 1.5절)로 판명.
- 이 구조적 한계를 인정하고, 불확실 구간을 **재검사**로 보내 미탐지 위험을 분산 → 2분법보다 현실적.
- 워밍업 구간 Recall 50% vs 안정 구간 23%(3.4절) → 안정 구간 불량이 재검사 구간의 주 대상.

## 5.6 불량 유형 군집화 (대응의 구체화)

- 불량 42건을 SHAP 상위 피처로 계층적 군집 → 3유형(A 급변동 / B 온도·금형 복합 / C 배럴온도). 3.3절.
- **연결**: 단일 "불량" 라벨을 **원인별로 분해**해 4장 공정 점검 가이드(4.3절)로 직접 연결 → "불량 예측"을 넘어 "불량 원인 진단"까지 확장.

## 5.7 차별성 한 줄 요약

"전통 제조업의 통계적 공정관리(SPC)와 EWMA 추세 신호를 ML 피처로 결합하고(포착률 +10%p), 잘 보정된 앙상블 확률(Brier 0.015)을 불확실성 3단계 판정으로 연결해, 미탐지가 불가피한 '측정 변수로 구분 불가 구간'을 재검사로 흡수하는 **진단형 품질 예측 체계**."
