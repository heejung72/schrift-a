# 5장 보고서 수치 — 창의성·차별성

평가 요건: 방법 나열이 아니라 **2·3장 결과와 연결**해 효과를 수치로 증명.
본 프로젝트의 중심 서사는 **"측정의 한계를 증명하고, 그 위에서 현장이 쓸 수 있는 시스템을 설계"**다.

## 5.1 「구분 불가」 증명 → 문제 재정의 ★ (최대 차별점)

- 대부분 참가자는 "F1 얼마"에서 멈춘다. 본 프로젝트는 **불량 86%(36/42)가 양품과 완전히 동일한 측정값**에서 발생함을 증명(3.3절)해, 문제를 **"불량 정확 예측"에서 "측정 한계 하의 검사 우선순위 최적화"로 재정의**했다.
- 이 관점이 이후 모든 설계(변화·추세 피처, 3단계 판정, 규칙)의 근거가 된다.
- **수상 포인트 연결**: 과거 수상 심사의 "성능 수치보다 해석", "알고리즘보다 문제를 푸는 관점"에 정확히 부합.

## 5.2 제조지식 + EWMA 추세 결합 피처

- 정적 수치의 한계를 **변화·추세 피처**로 보완: 가소화시간 변화량(delta)·6개 변수 EWMA 잔차·복합 이탈도(L2).
- **효과(3.1절)**: 실제 SHAP 1위 Plasticizing_Time_delta(0.96), 2위 ewma_resid_norm(0.91) — **상위 2개가 모두 '변화·추세' 피처**. 정적 수치가 동일해도(라벨 충돌) 시계열 맥락으로 신호 복원.
- **정직성**: 이산형 3σ 위반(spc_violation_count)은 이 데이터에서 0(미발동)이라, **연속형 EWMA 잔차가 SPC 역할을 수행**했음을 명시(3.1절 정정). → EWMA 관리도 = 전통 SPC와 ML의 실질적 결합.

## 5.3 사람이 읽는 공정 조건 규칙 (설명가능성)

- SHAP 상위 '변화·추세' 피처로 IF-THEN 규칙 R1~R3 도출(3.4절).
- **효과**: 규칙 3개(적용 21%)만으로 불량 **60% 포착**(lift 2.84배) — ML 모델(20%→62%)과 **거의 동등한 효율을 설명 가능한 규칙으로** 달성.
- 과거 수상작(공정 조건 규칙 도출형)과 같은 결을, 성능까지 붙여 구현.

## 5.4 불균형 학습 (1:56)

- class_weight="balanced"(LR·RF) + scale_pos_weight=55(LGB) + fold별 F1 최대화 임계값.
- **효과(2.2절)**: 기본 F1 0.222 → 임계값 최적화 0.266 → Rolling·SPC 피처 0.303.

## 5.5 근거 기반 앙상블

- RF(배깅) + LGB(부스팅) 소프트 보팅. **LR 의도적 제외** — 포함 시 PR-AUC 0.258→0.202 하락(2.3절).
- **효과**: 앙상블 F1 0.343(최고).

## 5.6 확률 보정 검증 (신뢰할 수 있는 확률)

- 3단계 판정·우선순위는 확률의 신뢰성이 전제. 앙상블 **Brier 0.015**로 베이스라인 **LR 0.163의 10배** 우수.
- isotonic 추가 보정 시 Brier 0.0151→0.0151(**개선 0%**) → **이미 잘 보정됨**을 교차검증으로 확인(신뢰도 곡선이 대각선에 근접, outputs/13_calibration.png).
- **의미**: 확률값 자체가 믿을 만해 우선순위·3단계의 수치 신뢰성이 검증됨.

## 5.7 불확실성 기반 3단계 판정 (미탐지 위험 분산) ★

- **불확실성 = 앙상블 멤버(RF↔LGB) 예측 불일치**로 정의(단순 percentile이 아닌 '진짜' 불확실성).
- **효과(3.7절)**: 불확실성 사분위별 불량률이 0.0%→0.7%→2.2%→**4.2%**로 단조 증가(상관 +0.27) — 모델이 헷갈리는 구간이 실제 위험 구간.
- 이를 3단계에 결합(高확률→즉시, **中확률 또는 高불확실→재검사**, else 통과): 검사량 21%로 불량 55% 포착.
- **연결**: 3.3절 '구분 불가' 불량 + 3.6절 FN을 재검사 구간으로 흡수하는 원리적 근거를 제공.

## 5.8 불량 유형 군집 → 원인 진단

- 불량 42건을 3유형(A/B/C)으로 군집화(3.5절) → "불량 예측"을 넘어 **"원인 진단 + 유형별 대책"**(4.4절)으로 확장.

## 5.9 운영 신뢰성 — 드리프트 인지 설계

- labeled↔운영(unlabeled) 분포 차이가 큼(PSI 다수 >1, 6장) → 이를 **한계로 숨기지 않고 모니터링·재학습 체계**로 설계(확장성).

## 5.10 차별성 한 줄

"불량 86%가 측정값만으론 구분 불가함을 증명하고, 그 위에 **변화·추세 피처 + 설명 가능한 규칙 + 보정된 확률 + 불확실성 3단계 판정**을 쌓아 '진단형 검사 우선순위 시스템'으로 완성 — 성능이 아니라 **문제를 보는 관점과 현장 실행성**으로 승부한다."
