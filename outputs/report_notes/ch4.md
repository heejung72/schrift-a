# 4장 보고서 수치 — 현장 활용방안

2·3장에서 검증한 모델과 분석 결과를 실제 생산라인에서 어떻게 쓰는지 4가지 축으로 정리한다.
모든 수치는 2·3장(CV holdout 2,393건) 결과와 동일하다.

## 4.1 사전 경보 (최종검사 이전 이상 예측)

- 공정 변수는 모두 **최종 검사 이전**에 기록된다(데이터 누수 없음, 1.8절). 따라서 사출 1회(1 shot)가 끝나는 즉시 불량 확률을 산출할 수 있다.
- 산출된 확률을 **3단계 등급**으로 변환해 작업자에게 바로 신호를 준다.

| 등급 | 기준(위험도 분위) | 현장 신호 | 작업자 행동 |
|---|---|---|---|
| 🔴 즉시검사 | 상위 5% | 적색 경보 | 해당 shot 검사 대기열 최우선 투입, 라인 정지 검토 |
| 🟡 재검사 | 상위 6~20% | 황색 주의 | 샘플 추출·재확인 예약 |
| ✅ 통과 | 하위 80% | 정상 | 정상 생산 지속 |

- 경보는 **확률값 + 등급 + 권장 조치**를 함께 제시한다(앱 `POST /predict` 응답 형식과 동일).

## 4.2 품질검사 우선순위 (핵심 가치)

3장 검사 우선순위 곡선을 현장 KPI로 환산한다.

| 검사 예산 | 불량 포착률 | 전수검사 대비 | 무작위 대비 |
|---|---|---|---|
| 상위 10% | 36% | 검사량 90% 절감 | 3.6배 |
| **상위 20%** | **62%** | **검사량 80% 절감** | **3.1배** |
| 상위 30% | 76% | 검사량 70% 절감 | 2.5배 |

**핵심 문장:**
"전수검사 대비 검사 대상을 20%로 줄이면서 불량의 62%를 사전에 포착한다. 검사 인력·시간이 제한된 라인에서 **위험도 상위 shot부터 검사**하도록 대기열을 자동 정렬하여, 같은 검사량으로 무작위 대비 3.1배의 불량을 잡아낸다."

- 앱 `GET /inspection-queue`: 미처리 shot을 **불량 확률 내림차순**으로 반환 → 검사원이 위에서부터 처리.

## 4.3 공정 점검 (이상 원인 진단)

3장 영향 변수·군집 결과를 "무엇을 점검할지"로 연결한다.

**조기 이상 신호 (SHAP Top4):**
- `ewma_resid_norm`(복합 이탈도)·`spc_violation_count`(SPC 위반)가 상승하면 **불량 발생 이전에** 공정이 흔들리고 있다는 뜻 → 설비 점검 트리거.
- 전통 SPC 관리도(3-sigma)와 ML 확률을 **함께** 보므로, 둘 다 높을 때 우선 대응.

**불량 유형별 점검 가이드 (3장 군집 A/B/C):**

| 유형 | 비중 | 신호 | 점검 대상 |
|---|---|---|---|
| A 공정 급변동형 | 4건 | ewma_resid_norm 극단값 | 즉시 공정 정지 검토 |
| B 온도편차·금형닫힘 복합형 | 17건 | barrel_temp_range↑, Clamp_Close_Time↑ | 금형 온도·형체압력 점검 |
| C 배럴 온도 편차형 | 21건 | barrel_temp_range↑ | 배럴 히터·온도 제어 확인 |

## 4.4 작업자 의사결정 지원 (대시보드)

FastAPI + 실시간 대시보드로 위 기능을 한 화면에 시연한다(3페이지 SPA).

| 페이지 | 역할 | 현장 의미 |
|---|---|---|
| 실시간 모니터링 | KPI + 불량확률 스트림 + 검사 대기열 | 교대 근무자가 라인 상태를 한눈에 파악 |
| 모델 성능 | 지표·모델 비교·영향 변수 | 품질 담당자가 모델 신뢰도·근거 확인 |
| 검사 우선순위 | 우선순위 곡선·3단계 판정·불량 유형 | 검사 계획 수립, 검사 예산 대비 효과 설명 |

- 시뮬레이터(`app/simulator.py`)가 unlabeled 데이터를 실시간처럼 흘려보내며, 서버가 shot마다 확률·등급을 계산해 대기열에 쌓는다.
- `POST /predict` 1건당 응답에 **최근 10 shot의 Rolling·SPC 피처까지 반영**(금형별 독립 계산)하여, 실제 운영과 동일한 추세 기반 판정을 재현한다.

## 4.5 기대 효과 요약

- 검사 비용: 검사량 80% 절감(상위 20% 검사)하면서 불량 62% 포착.
- 불량 유출 방지: 즉시검사(상위 5%)만으로 불량 31% 선제 차단.
- 공정 안정화: SPC·EWMA 조기 신호로 불량 발생 **이전** 설비 점검 가능.
- 현장 수용성: 확률이 아닌 **3색 등급 + 권장 조치**로 제공해 비전문가도 즉시 활용.
