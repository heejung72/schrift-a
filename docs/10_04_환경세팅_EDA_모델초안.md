## 1장 EDA — 핵심 발견

### 데이터 파일 구성

| 파일 | 행 수 | 역할 |
|---|---|---|
| moldset_labeled_cn7.csv | 1,211 | 학습 (cn7 금형, 라벨 있음) |
| moldset_labeled_rg3.csv | 1,182 | 학습 (rg3 금형, 라벨 있음) |
| moldset_unlabeled_cn7.csv | 35,239 | 테스트 (예측 대상) |
| moldset_unlabeled_rg3.csv | 35,941 | 테스트 (예측 대상) |

### 생산단위
**1행 = 1 Shot** (사출 1회 사이클). `Unnamed: 0` = Shot 순번(단조증가).

### 변수 목록 (25개 피처 + 타깃)

| 그룹 | 변수 (개수) | 비고 |
|---|---|---|
| 사이클 시간 | Injection_Time, Filling_Time, Plasticizing_Time, Cycle_Time, Clamp_Close_Time (5) | |
| 위치 | Cushion_Position, Plasticizing_Position, Clamp_Open_Position (3) | **Clamp_Open_Position: labeled 전부 0 → 제거** |
| 속도/회전 | Max_Injection_Speed, Max_Screw_RPM, Average_Screw_RPM (3) | |
| 압력 | Max_Injection_Pressure, Max_Switch_Over_Pressure, Max_Back_Pressure, Average_Back_Pressure (4) | |
| 온도 | Barrel_Temperature_1~6, Hopper_Temperature, Mold_Temperature_3~4 (9) | |
| 타깃 | **PassOrFail** (0=양품, 1=불량) | 학습 데이터에만 존재 |

> **모든 수치 변수 이미 Z-score 정규화 완료 (mean≈0, std≈1).**  
> 재정규화 불필요.

### 타깃 — 클래스 불균형

| 금형 | 불량 수 | 양품 수 | **불량률** |
|---|---|---|---|
| cn7 | 17 | 1,194 | **1.4%** |
| rg3 | 25 | 1,157 | **2.1%** |
| 합계 | **42** | 2,351 | **1.75%** |

불량:양품 ≈ 1:57. Accuracy는 주 지표로 사용 금지. **F1-score 사용.**

### 정규화 방식 확인
- labeled_cn7 + unlabeled_cn7 → **쌍으로 함께 정규화** (cn7 단위)
- labeled_rg3 + unlabeled_rg3 → **쌍으로 함께 정규화** (rg3 단위)
- **cn7와 rg3의 수치 절대값 비교 불가** → `mold` 변수(cn7=0, rg3=1) 필수

### 결측·중복·이상치

| 항목 | 내용 |
|---|---|
| 결측값 | **없음** (4개 파일 모두) |
| 중복 행 | labeled 약 50% — 연속 2개씩 동일 (안정 구간 반복). **유지** |
| 라벨 충돌 | cn7 11건, rg3 25건 (동일 피처값에 양품·불량 혼재). 1장에 "측정 변수로 구분 불가 구간"으로 기록. 5장 불확실성 판정의 근거 |
| 이상치 | |z|>3인 행 0.3~1.4% (Plasticizing_Time 최대 z=20). 센서 오류 추정 |

### 행 순서 = 시간 순서 (근거 5가지)

1. `Unnamed: 0` 단조증가·중복없음 (Shot counter)
2. Lag-1 자기상관: Mold_Temperature_3=**0.995**, Clamp_Close_Time=0.975, Injection_Time=0.921 (열관성 등 물리적으로 당연)
3. 공정 변수의 점진적 드리프트 (워밍업→안정화)
4. cn7 불량 17개가 **Shot 47~120 (앞 10%)에만 집중** → 기계 초기 워밍업 구간 불량
5. unlabeled 최빈 간격=1 (42.7%) → 연속 shot 샘플링 패턴

### cn7 불량 군집 — 중요 발견
cn7 불량 17개가 전부 앞 10% (Shot 47~120)에 집중. rg3는 전체에 분산.  
→ **워밍업 구간**에 불량 집중 → 3장 FN/FP 분석의 핵심 공정조건  
→ 시간순 80/20 분할 시 cn7 불량 17개가 모두 학습세트에 들어가 검증 불가  
→ **StratifiedGroupKFold 채택 이유**

### 데이터 누수
없음. 모든 변수가 최종 검사 전 공정 중 기록.

### 검증 전략

| 방법 | 설명 |
|---|---|
| **기본: StratifiedGroupKFold 5×10** | 연속 중복 쌍을 같은 fold에. 불량 fold별 균등 배분. fold당 불량 ~8개 |
| 보조: 금형 교차검증 | cn7→rg3, rg3→cn7. 단, 금형별 정규화로 F1=0 → 한계로 기록 |

## 2장 모델 비교 — 초안 결과

**설정**: StratifiedGroupKFold 5-fold × 10회 반복, 각 fold에서 F1 최적 임계값 탐색

| 모델 | **F1** | Recall | Precision | PR-AUC | 임계값 |
|---|---|---|---|---|---|
| 로지스틱회귀 (베이스라인) | 0.274 ± 0.154 | 0.291 | 0.547 | 0.188 | 0.857 |
| RandomForest | **0.297 ± 0.134** | 0.294 | 0.531 | 0.207 | 0.167 |
| LightGBM | 0.266 ± 0.201 | 0.181 | 0.611 | **0.230** | 0.277 |
| 앙상블 (LR+RF+LGB) | 0.285 ± 0.156 | 0.311 | 0.599 | 0.202 | 0.334 |

> F1이 낮아 보이는 이유: 불량 42개라는 극소수. 무작위 F1≈0.035 대비 모델은 8배 이상 높음.  
> **PR-AUC 기준 LightGBM이 무작위(0.018)의 14배** → 불량 위험 순위를 학습하고 있음.

**금형 교차검증 (LightGBM)**: cn7→rg3, rg3→cn7 모두 F1=0.  
원인: 금형별 독립 정규화로 수치 스케일이 달라 직접 적용 불가. 1장 한계로 기록.

### 검사 우선순위 효과 (CV holdout 기반)
- 전수검사 대비 검사량 **70% 감소** → 불량 **74% 포착**
- 전수검사 대비 검사량 **80% 감소** → 불량 **55% 포착**
- 전수검사 대비 검사량 **90% 감소** → 불량 **36% 포착**

### 3단계 판정 (CV 기반, 임계값 lo=0.10, hi=0.35)
| 구간 | 건수 | 실제 불량 | Precision |
|---|---|---|---|
| 즉시 검사 (prob≥0.35) | 9건 (0.4%) | 7개 | 77.8% |
| 재검사 (0.10~0.35) | 5건 (0.2%) | 1개 | 20% |
| 통과 (prob<0.10) | 2,379건 (99.4%) | 34개 | — |

> 임계값 최적화 여지 많음. 10/05에 개선 예정.
