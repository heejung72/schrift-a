조사일: 2026-10-04
목적: 이전 수상작의 공통점을 이번 실험 설계와 보고서에 반영하기.
원칙: 구조와 수준만 참고하고, 문장·코드·그래프는 가져오지 않는다.

## 1. 확인된 수상작

수상작의 보고서나 코드 원본은 공개된 것을 찾지 못했다. 아래는 수상 소식 기사에서 확인한 내용이다.

| 대회 | 수상 | 팀 | 주제 | 방법 |
|---|---|---|---|---|
| 제2회 (2022) | 대상 | 중앙대 DataIntelligenceLAB | 용해탱크 불량 탐지 | 반지도학습, 여러 시나리오로 확장 가능한 모델 |
| 제2회 | 최우수 | 서울과기대 LPK | 양품 생산을 위한 용해공정 최적화 규칙 | 공정 조건 규칙 도출 |
| 제2회 | 최우수 | 국민대 | 제품 품질 예측 | 시계열 분석 |
| 제2회 | 우수 | 한양대 Optimus Factory | 불량 사전 예측 | 예측 모델 |
| 제2회 | 장려 | 성균관대 Last Spark | 원재료 특성을 반영한 불량 예측 | 설명 가능한 AI(XAI) |
| 제2회 | 장려 | STAPRER | 현장 대응형 공정 판정 알고리즘 | 판정 알고리즘 |
| 제3회 (2023) | 최우수 | 한양대 ERICA 왕십리분석혁명가들 | 열처리 설비 이상 실시간 탐지 | XAI, 실시간 적용 |

- 제2회 참가 153팀, 제3회 참가 184팀, 서면평가로 8팀 선정 후 발표평가.

## 2. 심사에서 반복되는 평가 포인트

1. **문제해결의 독창성**: 새 알고리즘 자체보다 문제를 푸는 관점
2. **실제 제조현장 적용 가능성**: 모델 결과가 현장 조치로 이어지는가
3. **설명 가능성(XAI)**: 왜 불량으로 판단했는지 설명
4. **실시간·운영 형태**: 현장에서 돌아가는 형태로 구현
5. **분석의 타당성과 결과 해석**: 성능 수치보다 해석의 깊이
6. **확장성**: 다른 조건·시나리오에도 적용 가능한가

## 3. 이번 프로젝트에 반영

| 평가 포인트 | 우리 설계 | 보고서 위치 |
|---|---|---|
| 설명 가능성 | SHAP 변수 중요도, SHAP 상호작용값 | 3장 |
| 현장 적용 가능성 | 3단계 판정(즉시 검사 / 샘플·재검사 / 통과), 검사 우선순위 곡선 | 4장 |
| 실시간·운영 형태 | FastAPI 예측 API, 검사 대기열, 실시간 시뮬레이터, 대시보드 | 4장, 5장 |
| 독창성 | 불확실성 기반 판정으로 FN 집중 조건을 재검사 구간에 배치 | 5장 |
| 해석의 타당성 | FN/FP가 몰리는 공정조건 분석, 제조지식 기반 해석 | 3장 |
| 확장성 | 설비·금형 단위 그룹 검증으로 새 설비에서의 일반화 확인 | 1장, 2장 |

추가로 고려할 만한 것:
- 제2회 최우수(LPK)처럼 **사람이 읽을 수 있는 공정 조건 규칙**으로 결과를 정리하면 현장 활용성이 높아 보인다.
  예: "금형 온도 ○℃ 미만이면서 사출 압력 ○ 이상이면 불량 위험 높음"
- 모든 분석 결과를 "그래서 현장에서 무엇을 하나"라는 한 문장으로 마무리한다.

## 4. 주의사항

- GitHub에 있는 KAMP 관련 저장소 대부분(26KAMP, 6th_KAMP, wootangies, kamp-2026-datada,
