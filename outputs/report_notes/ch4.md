# 4장 보고서 수치 — 현장 활용방안

2·3장 결과를 "사전 경보 → 검사 우선순위(경제성) → 공정 점검(대책) → 작업자 지원 → 도입 로드맵"으로 연결한다. 모든 수치는 CV holdout(2,393건) 기준.

## 4.1 사전 경보

공정 변수는 모두 최종 검사 이전에 기록(누수 없음)되므로, shot 종료 즉시 불량 확률 + 3단계 등급 + 권장 조치를 산출한다.

| 등급 | 기준 | 신호 | 작업자 1차 행동 |
|---|---|---|---|
| 🔴 즉시검사 | 상위 5% | 적색 | 검사 최우선 + 라인 정지 검토 |
| 🟡 재검사 | 상위 6~20% | 황색 | 샘플 추출·재확인 |
| ✅ 통과 | 하위 80% | 정상 | 생산 지속 |

## 4.2 검사 우선순위 + 경제성 ★

**포착 효율:**

| 검사 예산 | 포착률 | 전수 대비 검사량 | 무작위 대비 |
|---|---|---|---|
| 상위 10% | 36% | −90% | 3.6배 |
| 상위 20% | 62% | −80% | 3.1배 |
| 상위 30% | 76% | −70% | 2.5배 |

**경제성 환산 (가정 명시, 블라인드):**
- 가정: 검사 1건 비용 = 1단위, 불량 1건 유출 손실 = K단위. 생산 10,000 shot/일, 불량률 1.75% → 불량 175건.

| 전략 | 검사비 | 유출 불량 | 총비용(검사비+유출손실) |
|---|---|---|---|
| 전수검사 | 10,000 | 0 | 10,000 |
| 상위 20% 검사 | 2,000 | 66건(38%) | 2,000 + 66K |
| 상위 30% 검사 | 3,000 | 42건(24%) | 3,000 + 42K |

- 상위 20%가 전수검사보다 저렴한 조건: 2,000+66K < 10,000 → **K < 121** (유출손실이 검사비의 121배 미만이면 비용 우위).
- 유출 손실이 큰 핵심 부품이면 상위 30%(유출 24%)로 올려 안전마진 확보.

**핵심 문장:** "검사 리소스가 제한된 라인에서 위험도 상위부터 검사해 **검사량 80% 절감 + 불량 62% 포착**. 유출 비용 수준(K)에 따라 검사 비율(10/20/30%)을 조정하는 비용 최적 운영이 가능하다."

## 4.3 공정 점검 — 규칙 기반 경보 (3장 R1~R3)

| 규칙 | 경보 의미 | 즉시 조치 |
|---|---|---|
| R1 복합 공정 이탈 | 여러 변수가 추세 이탈(급변동) | 직전 10샷 추세·설비 상태 점검, 지속 시 라인 정지 |
| R2 가소화시간 급변 | 가소화 공정 불안정 | 스크류 회전·백압·원료 수분 점검 |
| R3 온도편차·금형닫힘 복합 | 금형·온도 복합 이상 | 금형 체결·형체압력·배럴 온도 점검 |

## 4.4 현실적 대응방안 (불량 유형별 대책)

3장 군집 A/B/C를 **단기 조치 + 장기 대책**으로 구체화:

| 유형 | 단기 조치 (즉시) | 장기 대책 (근본) |
|---|---|---|
| A 공정 급변동 (4건) | 즉시 공정 정지 검토, 직전 샷·설비 점검 | 급변동 트리거 원인(원료 투입·스크류 마모·유압) 설비 보전 이력화, 자동 정지 임계 연동 |
| B 온도편차·금형닫힘 (17건) | 금형 체결·형체압력 점검, 금형 온도 분포 확인 후 재검사 | 금형 보전주기 단축, 형체압력 상시 모니터링, 금형별 온도 관리도 운영 |
| C 배럴 온도 편차 (21건) | 배럴 히터·열전대 점검, 온도 안정 후 샘플 재검사 | 배럴 구간별 히터 PID 재튜닝, 열전대 교정주기 관리, 편차 경보 자동화 |
| 구분 불가 (재검사) | 측정값 정상이라 샘플 재검사로 분산 | **비전검사·X-ray 등 측정 외 검사축 추가** (측정 한계 보완) |

## 4.5 작업자 의사결정 지원 (대시보드 + 앱)

FastAPI + 실시간 대시보드로 시연(3페이지 + 작업자용 shot 상세):
- **작업자용 "왜 + 무엇을"**: 플래그된 shot을 클릭하면 ① 불량 확률·등급 ② 어떤 규칙(R1~R3)이 발동했는지 ③ 추정 불량 유형(A/B/C) ④ 구체적 조치를 한 화면에 제시 → 비전문가도 즉시 행동.
- 확률 대신 **3색 등급 + 규칙 설명 + 조치**로 제공해 현장 수용성 확보.

## 4.6 단기 / 장기 도입 로드맵

| 단계 | 기간 | 내용 |
|---|---|---|
| **단기 (PoC)** | 0~1개월 | 기존 라인에 예측 API + 대시보드 연결, 상위 20% 우선검사 + R1~R3 경보 운영, 작업자 교육 |
| **중기 (파일럿)** | 1~3개월 | 1개 금형 라인 파일럿, 실제 검사결과 피드백으로 라벨 축적, 3단계 임계값 현장 보정, **드리프트 모니터링 가동**(6장) |
| **장기 (확산)** | 3개월~ | 신규 금형·설비로 재학습·확장, 비전검사 등 측정 외 검사축 추가, MES·품질시스템 통합, 자동 공정 정지 연동 |

**근거**: 6장 드리프트 분석에서 labeled↔운영(unlabeled) 분포 차이가 크므로(PSI 다수 >1), **파일럿 단계의 현장 재학습·임계값 보정이 필수**다.
